This namespace documents the service from an operator's and user's perspective. Protocol v2 replaced v1 pairing with one optional static shared secret and one client config file; v1 pairing, installation keys, and allowlists no longer exist and there is no automatic migration.

Use **[Start and configure the relay server](./start-relay-server/)** to build the Go process, select a loopback port, choose authentication-off or shared-secret mode through one mode-`0600` secret file, and migrate a v1 deployment.

Use **[Install and configure the relay extension](./install-relay-extension/)** to deliver the loopback endpoint and optional shared secret through one mode-`0600` client config file.

Use **[List online relay peers](./list-peers/)** to read bounded live address-only pages, continue with an opaque cursor, and refresh after presence changes.

Use **[Send an online message](./send-message/)** for provenance-labelled string or JSON-object delivery, result meanings, extension single-flight, and the relay's per-sender in-flight capacity.
