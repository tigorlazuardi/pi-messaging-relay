This namespace documents the service from an operator's and user's perspective.

Use **[Start and configure the relay server](./start-relay-server/)** to build the Go process, select a loopback port, choose temporary or durable allowlist state, and obtain a startup code through a private operator file.

Use **[Install and pair the relay extension](./install-relay-extension/)** to configure the loopback endpoint and establish one Ed25519 installation identity with `/relay-pair CODE`. Session authentication is available, but `list_peers` and `agent_send` remain disconnected while roster and delivery are deferred.
