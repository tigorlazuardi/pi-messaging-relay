This namespace documents the service from an operator's and user's perspective.

Start with **[Start the relay server](./start-relay-server/)** to build the Go process, select a loopback port, observe readiness, and stop it cleanly.

The accepted relay v1 contract also covers future client extension installation, pairing, peer discovery, message sending, security, and operational limits. Those capabilities are not implemented by the current process lifecycle slice.
